# 💸 BudgetIQ – Financial Behaviour Analyzer

BudgetIQ is a smart web-based application designed to analyze user spending patterns and provide meaningful financial insights. It helps users understand their financial behaviour and make better budgeting decisions.

---

## 🚀 Features

* 📊 Track income and daily expenses
* 🧠 Financial Behaviour Analysis
* 📈 Visual Insights Dashboard with interactive charts
* 💡 Categorization of expenses
* 📉 Helps identify overspending habits
* 📱 Modern Glassmorphism UI with responsive design

---

## 🧠 Financial Behaviour Analyzer

The core idea of this project is to:

* Analyze user spending patterns
* Identify trends (e.g., frequent categories, high spending areas)
* Provide insights to improve financial decisions

---

## 🛠️ Tech Stack

### 💻 Frontend

* HTML
* CSS
* JavaScript
* Chart.js (for data visualization)

### ⚙️ Backend

* Supabase (Backend-as-a-Service)
* Handles API requests and data operations

### 🗄️ Database

* PostgreSQL (via Supabase)
* Stores transaction data (income, expenses, categories)
* SQL used for querying and analysis

---

## ⚙️ How It Works

1. User enters income and expense data
2. Data is stored in Supabase (PostgreSQL database)
3. System retrieves and processes data using SQL queries
4. Insights are generated based on user transactions
5. Results are displayed on the insights dashboard

---

## 📂 Project Structure

* `index.html` → Main interface (Login)
* `insights.html` → Financial insights dashboard
* `insights.js` → Logic for fetching Supabase data and rendering Chart.js
* `style.css` → Global styles including modern glassmorphism UI and animations
